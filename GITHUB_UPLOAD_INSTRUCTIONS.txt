UNDERWORLD MOD — GITHUB ACTIONS BUILD
=====================================

1. Extract this ZIP.
2. Open https://github.com/beq2180/gpt-underworld
3. Click Add file -> Upload files.
4. Drag ALL CONTENTS of the extracted folder into the upload area.
   IMPORTANT: .github is a hidden folder on macOS.
   In Finder press Command + Shift + . if you need to reveal hidden files.
5. Commit the files to the main branch.
6. Open the Actions tab in GitHub.
7. Click "Build Underworld Mod".

The workflow starts automatically after the commit. If it succeeds, its
"underworld-fabric-1.21.11" artifact contains the compiled JAR(s).

If it fails, don't try to fix it yourself. Tell ChatGPT that the Action ran;
ChatGPT can read the workflow logs from the repo and diagnose the compiler
errors.
